# DynamicProjectilePlugin — unit test projects

Generated by `generate_test_projects.js` in the GBStudio Plugin Patch Builder. Each folder is
a GB Studio project that installs this plugin in one configuration and exists to prove that
configuration still compiles. Build them all with `build_examples.js --tests`.

Every project carries one scene of each scene type, because GB Studio only compiles the state
file for a scene type the project uses.

| Project | What it covers |
|---|---|
| `DEFAULT` | DynamicProjectilePlugin on its own, every engine setting at its default. |
| `ALT_Sce_DynamicA_Spr` | DynamicProjectilePlugin with SceneStackExPlugin, DynamicActorPlugin, SpritesheetChangeBufferPlugin — selects engineAlt/Sce_DynamicA_Spr. |
| `ALT_DynamicA_Spr` | DynamicProjectilePlugin with DynamicActorPlugin, SpritesheetChangeBufferPlugin — selects engineAlt/DynamicA_Spr. |
| `ALT_Sce_DynamicA` | DynamicProjectilePlugin with SceneStackExPlugin, DynamicActorPlugin — selects engineAlt/Sce_DynamicA. |
| `ALT_Sce_Spr` | DynamicProjectilePlugin with SceneStackExPlugin, SpritesheetChangeBufferPlugin — selects engineAlt/Sce_Spr. |
| `ALT_DynamicA` | DynamicProjectilePlugin with DynamicActorPlugin — selects engineAlt/DynamicA. |
| `ALT_Sce` | DynamicProjectilePlugin with SceneStackExPlugin — selects engineAlt/Sce. |
| `ALT_Spr` | DynamicProjectilePlugin with SpritesheetChangeBufferPlugin — selects engineAlt/Spr. |
